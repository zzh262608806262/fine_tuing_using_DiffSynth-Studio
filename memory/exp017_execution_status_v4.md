## 🔧 蒸馏训练的时间特性

### 为什么蒸馏这么慢？

**正常训练**：
- 每step：1次前向 + 1次反向 + loss计算
- 时间：~16秒/步

**蒸馏训练**：
- 每step：30次teacher前向（完整推理）+ 1次loss计算 + 反向传播
- 时间：~72秒/步（4.5倍慢）

这是**蒸馏的本质**：学生模型学习用4步复现老师30步的结果。
