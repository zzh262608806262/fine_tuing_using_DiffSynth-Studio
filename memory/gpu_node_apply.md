# GPU 节点申请与连接方法

> 集群：Berzelius。新建的终端**默认没有 GPU**，需要先申请一个计算节点，并在其中运行需要 GPU 的命令。

## 一图流（常用命令）

```bash
init1g          # 申请一个普通 GPU 结点（40G 级 A100）
init1gf         # 申请一个 80G GPU 结点（fat 分区，A100 80GB）
squeue --me     # 查看当前自己的作业/结点（已申请到哪些节点）
jobsh <node>    # 进入指定结点（如 jobsh node084），在里面跑 GPU 命令
scancel <jobid> # 删除/释放结点（scancel 作业号）
```

## 详细说明

### 1. 申请 GPU 结点
- `init1g`：申请一个**普通 GPU** 结点（40G 级）。
- `init1gf`：申请一个 **80G** 结点（fat 分区，A100 80GB），跑大模型/长序列时用。
- 申请成功后会返回一个**作业号（jobid）和结点名（node 编号）**。

### 2. 查看自己已有的结点
```bash
squeue --me
```
- 列出自己当前所有挂起的/运行的作业与结点。
- **这个服务器很多人共用**：只允许进入**自己申请**的结点，**不要进入别人申请的结点**（影响他人工作，也违反使用约定）。

### 3. 进入结点执行 GPU 命令
```bash
jobsh <node>        # 例如 jobsh node084
```
- 进入后，该终端才有 GPU 可用；在此终端内跑训练/推理。
- 等价替代：`srun --overlap --jobid=<已有作业>` 挂进自己已有的 GPU 分配。

### 4. 用完释放结点
```bash
scancel <jobid>     # 例如 scancel 17343164
```
- 删除作业即释放 GPU，避免白白占用资源影响他人。

## 注意事项
- 新建终端默认无 GPU，直接跑 GPU 命令会报错/无设备；必须先 `init1g`/`init1gf` 申请。
- 不要占用或进入他人结点；用完及时 `scancel` 释放。
- 如需批量提交长时间任务，用 `sbatch <脚本>`（见 `slurm/*.sbatch`），而非手动申请终端。
